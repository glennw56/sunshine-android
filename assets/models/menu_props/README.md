# Menu props (Explore 3D)

Drop **Godot 4 .glb** files here. Explore instances every real mesh (root not
`PLACEHOLDER_*`) onto the outdoor eating patio — tables, seating, and the
ground near chairs. These are **walkable map items**, not the Order screen.

This folder is the Square-photo remake pack (`prop_*.glb`, ~64 items).
3D Models textures each prop from real Sunshine Square catalog photos,
not invented fantasy food.

Drinks go on the center/bistro tables first; croissants, savory, cakes,
rolls, cookies, and macarons fill picnic tables and ground near seating.
Extra `prop_*.glb` files still spawn near seating (not the south-lawn
spawn axis).

Units: meters, Y-up, identity attach. Origin is the mesh bottom.
