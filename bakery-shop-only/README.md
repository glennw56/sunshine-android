# Shop-only Explore refs

Elevation + photo refs for the walkable shop mesh
`assets/models/sunshine_shop_grass.glb`. Rebuild with:

```bash
python3 tools/build_shop_grass_glb.py
```

## What the mesh must include

| Ref | Must show |
| --- | --- |
| Street photo | White clapboard, pink trim, circular logo, orange **SUNSHINE'S BAKERY** sign, two dark windows, stacked **2231**. No street door. |
| Entrance elevation | Wooden ADA ramp + rails, double doors, wreath, door lantern, two side windows, AC, downspout, roof vents. |
| Side elevation | Windows (one **barred**), single door + three stairs + rails, AC, electrical box, chimney + flue. |
| Back elevation | Gable + louver vent, back door, deck rail, stairs, stem-wall **foundation hatch**. |

## What must not appear

Neighbor house, trees, cars, train, picnic extras, or porches that are not in those refs.

The **main menu** stays `assets/branding/storefront-hero.jpg`. This mesh is Explore only.
